The model is downloaded straight into this repo's models/ folder and runs entirely on this machine — nothing you scrape ever leaves your disk.
Local inference runs on this machine's own CPU/GPU and RAM — nothing offloaded to a server. Make sure your hardware can actually handle the model you pick: a bigger model needs more memory just to load, and inference time scales with your available resources too, so the same model can take seconds on a strong GPU and minutes on a modest CPU.

The model must be in GGUF format (e.g. a repo ending in -GGUF (recc. unsloth models)).

Some models require a Hugging Face token to download.

The bigger and more capable the model, the better the analysis it can produce.

This model needs a Hugging Face token — or add HF_TOKEN to your .env instead.
